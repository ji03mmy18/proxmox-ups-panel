# proxmox-ups-panel — dev-notes

This branch preserves the development specification documents written in Traditional Chinese (zh-TW) during the design and implementation of proxmox-ups-panel.

The documents are not part of the software release and are not required to build or use the package. They are kept here for historical reference.

For the project source code, installation instructions and documentation, see the [`main`](../../tree/main) branch.
