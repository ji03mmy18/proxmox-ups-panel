# PVE UPS Panel — i18n 國際化實作

## 前置確認

**開始實作前，請先執行以下指令確認環境：**

```bash
# 確認語系檔實體路徑
find /usr/share/pve-manager /usr/share/pve-i18n \
    -name "pve-lang-zh_TW.js" 2>/dev/null

# 確認語系檔格式（前 30 行）
find /usr/share/pve-manager /usr/share/pve-i18n \
    -name "pve-lang-zh_TW.js" | head -1 | xargs head -30

# 確認 index.html.tpl 載入語系檔的行號與格式
grep -n "pve-lang\|locale\|i18n" \
    /usr/share/pve-manager/index.html.tpl
```

**語系檔的格式與放置路徑必須與現有 PVE 語系檔完全一致。**

---

## 語系檔放置位置

放在與現有 `pve-lang-*.js` 相同的目錄，
檔名格式：`pve-ups-lang-{lang}.js`

---

## index.html.tpl 修改

在現有語系載入行的**正後方**插入一行，
通過 `postinst` 的 `dpkg-divert` 機制處理：

```html
<!-- 原有，不動 -->
<script type='text/javascript'
    src='/pve2/locale/pve-lang-[% lang %].js?v=[% i18n_js_mtime %]'>
</script>
<!-- 插入這行，注意不加 ?v= 版本號 -->
<script type='text/javascript'
    src='/pve2/locale/pve-ups-lang-[% lang %].js'>
</script>
```

---

## pve-ups-panel.js 修改規範

所有面向使用者的字串一律改為 `gettext('English key')`：

```javascript
// ✗ 錯誤：硬編碼字串
title: '電池狀態',

// ✓ 正確：使用 gettext
title: gettext('Battery Status'),
```

**Key 命名規則：**
- 統一英文
- 完整單字，不縮寫
- 專有名詞保持原樣（`UPS`、`NUT`、`N/A`）
- 與 PVE 現有翻譯衝突時，優先復用 PVE 已有的 key

---

## 需要建立的語系檔

| 檔案 | 說明 |
|---|---|
| `pve-ups-lang-zh_TW.js` | 繁體中文（完整翻譯） |
| `pve-ups-lang-zh_CN.js` | 簡體中文（完整翻譯） |
| 其他所有 PVE 支援的語系 | 佔位空白檔（避免 404） |

其他語系佔位檔內容：

```javascript
// pve-ups-panel translations pending for this language
```

## 完成後驗證

```bash
# 1. 切換語言至 zh_TW
#    Datacenter → Options → Language → 繁體中文
#    重新整理瀏覽器，確認 UPS 面板字串正確顯示

# 2. 切換至沒有翻譯的語系（例如 de）
#    確認不出現 404，且 fallback 顯示英文 key

# 3. 確認語系檔可正常載入
systemctl restart pveproxy
curl -sk https://localhost:8006/pve2/locale/pve-ups-lang-zh_TW.js \
    | head -10

# 4. 確認語系載入順序正確（UPS 語系在 PVE 語系之後）
grep -n "pve-lang\|pve-ups-lang" \
    /usr/share/pve-manager/index.html.tpl
```
